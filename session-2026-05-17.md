## What Was Built

**Fixed Teams** — the host can pre-define player pairs ("Team 1 = Alice + Bob") and run a round-robin between those teams instead of the default fair-play rotation. This can be configured either:

1. **Pre-session** (in `StartDaySheet`) — before tapping "Start Day"
2. **Mid-session** (in `TournamentRoundView`) — anytime during an active day; the current round is never interrupted, new engine applies on the next freed court

### Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Mid-session switch behavior | No interruption — applies next freed court | Avoids disrupting ongoing matches |
| Team builder interaction | Tap-to-assign (not drag-and-drop) | Simpler touch interaction, works well on iPhone |
| Team naming | Auto only ("Team 1", "Team 2", …) | Minimal friction; host doesn't need to think of names |
| Player count per team | Exactly 2 (doubles) | Matches the existing 2v2 match structure |
| Round-robin scheduling | Least-played matchup first, random tiebreak | Fair distribution of games across all team pairs |

## Round-Robin Engine Design

```
N teams → N*(N-1)/2 unique matchups

Scheduling algorithm:
1. Enumerate all team pairs
2. Count play-count per pair from completedMatches
3. Sort by count ascending (fewest played first), random tiebreak
4. Assign to free courts — skip if either team already busy
5. After all matchups played equally, cycle restarts naturally
```

For a typical 6-team session (15 matchups, 2 courts): the engine distributes matches evenly, with every team playing roughly the same number of games over time.
