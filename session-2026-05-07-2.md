## Technical Decisions

| Decision | Rationale |
|---|---|
| `observeRegistrations` as `nonisolated` | Actor isolation prevents using `addSnapshotListener` callback with actor-bound methods; inline parsing avoids the issue |
| Host check-in only (no self-check-in) | Prevents fake check-ins; mirrors existing organizer-writes-only philosophy |
| `advanceCount` set AFTER group stage (not at creation) | Host can't know the right count before seeing how teams perform |
| Knockout pairing is random, not seeded | User explicitly wants random draw — keeps it fair and unpredictable |
| Group Stage lives inside Tournament as 3rd tab | Cleaner than a top-level concept; tournament already owns teams + context |
| "Tournaments" tab inside Tournament (confusing naming) | User's explicit choice — they want it as a sub-feature of an existing Tournament |
